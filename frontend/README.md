# Frontend

Vite + React UI for scanning AI engineering updates and preparing source-linked
briefings over the active time window and filters.

## Primary Experience

- Today, week, month, and all-time feed windows
- Compact tool, topic, event, source-type, and source filters
- Ranked update cards with developer impact
- Editorial featured story plus compact ranked issue entries
- Desktop issue-and-memo layout and mobile Stories/Briefing modes
- Brief, Sources, and Search Notes memo views
- Used citations separated from the full ranked search result set
- Bookmarkable filter state
- Responsive analysis-first mobile layout
